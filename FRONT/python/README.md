# ALEM Desktop

Основной интерфейс проекта — существующий Python/PySide6 GUI в `desktop.py`. Запускайте весь проект только из корня:

```bash
python main.py
```

GUI получает динамический `http://127.0.0.1:<port>` от launcher и не открывает браузер. API-клиент отклоняет любой не-localhost адрес. Blocking HTTP-запросы выполняются через `QThreadPool`, поэтому обработка и экспорт не блокируют Qt event loop.

Поддерживаются список встреч, поручения, live WAV recording, настройки/health, создание и загрузка, повторный анализ, полный player, seek по двойному клику на transcript, имя/роль участника, редактирование поручений и PDF/DOCX.

`requirements.txt` устанавливается только на этапе подготовки окружения. Runtime никогда не выполняет pip. Журналы launcher находятся в корневом `runtime/`.
